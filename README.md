# NZ Domestic Cricket Live

**Live site:** https://jakebnz.github.io/nzdclive/

Shows all live or scheduled NZ domestic cricket matches for the day at once.

## Filter by competition

To show matches from only one competition, use one of these links:

| Competition | URL |
|-------------|-----|
| `Women's 1-Day` | https://jakebnz.github.io/nzdclive/hbj/ |
| `Men's 1-Day` | https://jakebnz.github.io/nzdclive/ft/ |
| `Men's 4-Day` | https://jakebnz.github.io/nzdclive/ps/ |
